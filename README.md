# AICodeDeployer

AI Code Deployer - parse AI responses and deploy projects

## Структура
```
PythonProject/
  .gitignore
  core/
    __init__.py
    deployer.py
    exporter.py
    parser.py
  main.py

```

## Установка
```bash
pip install -r requirements.txt
```

## Запуск
```bash
python main.py
```
